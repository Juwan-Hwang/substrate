# Durable Objects

Durable Objects provide single-threaded consistency at the edge. We use them
for real-time presence, experiment state synchronisation, and collaborative
sessions.

## WebSocket Hibernation

Cloudflare's WebSocket Hibernation API allows Durable Objects to sleep when
no active messages are flowing, reducing costs dramatically.
